# Contributing to Hedwig

Thanks for your interest in Hedwig. This document is a placeholder — full
contribution guidelines will land alongside the first `packages/*` release.

## Working on the repo today

- **Requirements:** Node.js ≥ 18.17, npm 9+.
- Install: `npm install`
- Run the reference demo: `npm run dev:demo`

## Structure at a glance

- `packages/` — publishable `@hedwigjs/*` packages (empty until first release).
- `examples/` — reference apps. `advanced/` is the kitchen-sink stand.
- `docs/content/` — documentation source (Markdown).
- `tooling/` — internal dev configs (planned).

## Reporting issues

Open an issue in the GitHub tracker with a minimal reproduction.

## Pull requests

Not accepting external PRs while the API is unstable. Feature ideas and bug
reports welcome via issues.
