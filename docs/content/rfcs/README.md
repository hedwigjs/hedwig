# RFCs

Short design records for non-trivial decisions. One decision per file. Each
RFC has a stable number and a status: `Draft`, `Accepted`, `Superseded`,
`Withdrawn`.

We write an RFC when a decision:

- affects the public API of a `@hedwigjs/*` package,
- constrains contributors' choices going forward,
- has more than one plausible answer worth explaining.

We don't write an RFC for internal refactors, bugfixes, or reversible tweaks.
